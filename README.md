**Overview**

timing is a grid-based personal time tracking app that helps users record how they spend their day through a simple and visual interface.
Users can log recurring activities with presets, organize them into three core categories — Focus, Rest, and Other — and review how their time is distributed across the day.

**Key Features**
- Structured activity presets across three categories, making it easy to log time consistently based on personal routines.
- Tap-based time tracking from the home screen for fast activity recording.
- Daily and weekly insights, including timeline views, cumulative time by activity, category percentages, focus-rest balance, and weekly heatmaps.
- A visual grid layout that represents time clearly, using 5 minutes per cell and 1 hour per row for easy scanning.

**Why This Project Matters**

This project is designed for people who want to understand how they actually spend their time, not just plan it.
By turning abstract time into visible patterns and summaries, timing helps users build more intentional daily habits.

**How to Use**
1. Download and install the app.
2. Create presets for activities you do often.
3. Start tracking from the home screen and review your daily or weekly time patterns in the app.
